# 每日滨州文章与村庄资料

每日文章沿用 Oracle B 的 APScheduler，北京时间 00:30，每次运行最多发布一篇。进程重启不会发布文章。`editorial.py` 由 `main.daily_article` 调用。

- 范围：滨州历史人物、历史事件、美食、美景、好人好事。
- 全量分页读取已发、草稿、归档文章，以标题近似度、具体主体和永久来源记录去重，再由独立模型审核主题重复与事实依据。语义审核仍可能误判，不代表数学意义的零重复保证。
- 来源文字作为不可信参考材料。没有合格地方材料时跳过；不再用固定循环题库编造文章，也不复制原文充数。
- 配图提示来自正文主体、地点、年代。生成或上传失败停止发布，不拿无关风景图替代。主题插画明确标注 AI 创作，推送包含该配图。
- 使用文件锁、防重复日期 slug、持久化 ledger 与待发布记录；网络不确定时依靠网站已有 slug 恢复。通知调用前记录尝试，避免重复推送；通知失败不自动重发。

`data/editorial_ledger.json` 永久保存，不应清理；`editorial_pending.json` 用于恢复；`editorial_status.json` 记录最近结果。日志包含错误类型。原有 Pollinations 图片服务有过失败，需观察首次实际执行；质量门槛可能导致某日没有发布，这比编造事实或错图发布更可取。未发送额外测试推送。

## 验证

在 Linux 上运行 `python -m unittest -v test_editorial`。测试全部使用模拟外部服务，覆盖重复日期、持久记录、图片失败、外地材料、损坏记录、主题去重和发布后崩溃恢复。

## 村庄资料

`edge/village-sources.ts` 为《滨州市小康村志》46村章节索引；`edge/village-research.ts` 保存首批6村核对数据。该书1998年7月第1版，版次据镜像第53章版权页。人口土地时点以各章为准，绝不作为2026年现况。

新增 `/village-research/`，已明确身份的八里王、东寨子、姚家按滨城区+滨城镇+村名附加资料。其他同名或别名待核，不覆盖D1原始档案。此批不是全市村庄调查完成。公开镜像非独立第二证据；迁徙记载未与族谱互证。夸克分享内容尚未读取，不计入已处理资料。
