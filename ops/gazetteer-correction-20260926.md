# 主参考标准纠正

问题：上一批将《滨州市小康村志》的数值提升为主档案字段，违背用户指定以《滨州市地名志》为主的标准。不同书籍的历史时点与叙述被混合。所谓“来源核验”不等于与主参考原页一致。

本次目视核对用户PDF第12、20、41、42页：

|村庄|印刷页|原书“现有”人口|原书“现有”耕地|
|---|---|---|---|
|柳家|184|156人|205亩|
|姚家|191—192|98户375人|746亩|
|东寨子|213|80户350人|1000亩|
|八里王|213—214|120户458人|892亩|

具体统计年未在条目中明确，不能将“现有”解读成2026年。四条加上先前原页核验的北关、东街，共六条主参考记录。

人口差异可能为时点不同；八里王王氏“元代户”与补充书“明洪武迁入”的冲突则不能仅以年代差异解释。主档案按指定原书表述，补充书单列异文，尚未裁断哪一版本在历史上最终正确。

未逐页核验的旧记录改为“旧汇编·尚未逐页核验”。从本地清洗问题表生成1376个身份组合的精准隔离规则，用于重复人口、土地、建村和沿革值，以及无依据的姓氏推断；匹配区县、乡镇、村名和原字段值后，前台及API显示待核，不更改D1原始值。这是风险隔离，不代表1376村已完成纠错，也不保证全部规则均命中线上库。

测试覆盖：主参考优先、其他文献标识、同名村不串档、精确可疑值隔离、新值不误隔离、原始数据保留。全部村庄逐页核对尚未完成。
